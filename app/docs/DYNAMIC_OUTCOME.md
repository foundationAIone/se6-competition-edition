# Dynamic realization: demonstrated outcome and limits

Eight fresh parameter/label scenarios cover mathematical, relational, technical and mixed-business changes. Each lane executes 48 events in fresh backend processes, with its own persistent TaskStore. Source and scorer were frozen before a new seed and fixture; no complete scenario sequence duplicated development/bootstrap. Fixed grammars and some boundary probes repeat. This is not novel-domain comprehension.

Both lanes pass 232/232 operational bookkeeping checks. Overall totals are 388/388 versus 280/388. These correlated checks are not independent statistical trials. The ablation deliberately removes prior information: it is not direct Nemotron or a competent conventional agent. Actual dynamic model A/B/C conditions are unexecuted.

Retained state uses 46 native transition attempts / 44 executed actions, 344.4812 subprocess seconds and 323.8125 worker CPU seconds. Memory removal uses 30 / 28, 153.2987 seconds and 134.3594 CPU seconds. Provider calls, tokens and provider charges are zero; local money is unpriced. Retained state is about 2.25 times slower and uses about 2.41 times worker CPU in this instrumented test. The driver covers 498.9104 seconds end-to-end; separate scoring takes 0.1357 seconds / 0.1094 CPU seconds. Timings include source loading, replay and Python heap instrumentation; heap peaks exclude RSS/native allocations. Engineering, UI and unmeasured OS costs are not attributed to benchmark dollars.

The math example begins unresolved, derives am=11 and independent cm=3, refuses an unannounced remap, then corrects am to 10 while preserving cm=3. After a fresh process restore it derives the previously unasked relation am=-cm+13 without restating premises. This is transfer within one retained variable namespace, not a new-domain theorem. Relational correction preserves an independent queue fact. Business price/budget updates reuse retained quantity proofs with zero new native transitions; monetary arithmetic remains HOST computation. Technical fixture checks verify exact local bytes, not invoices or production approval; model-origin claims confer no spending authority.

The separate origin-gate mechanism test executes eight canonical receipts: when a weak host incorrectly marks model evidence valid, realize refuses while plain transition admits. When the host correctly marks it invalid, both refuse. This is a causal origin-gate ablation, not an independent model/agent comparison. Tampered journals are rejected in regression tests.

Demonstrated change is external persistent task knowledge and decisions made by fixed procedures. No learned-procedure change, sentience, universal comprehension, model-weight modification or cognitive improvement is established. Backend process restart tests are distinct from Codex agent cognition and a hosted server restart. Interactive judge sessions last ten minutes and four rounds; the benchmark's TaskStore journals persist separately on disk.

The public functional replay uses the exact pinned grader's functional definitions over sanitized captured values and generated truth parameters, published only after captures froze. It reproduces 156/156 and 48/156 without importing the native engine or making inference. Private process/store/authority checks are excluded from that public replay. Local hashes do not establish external origin, signatures or chronology. Full private captures are preserved; receipt/state field projections are not full journal proofs.
