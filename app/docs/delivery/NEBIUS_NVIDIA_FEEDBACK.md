NVIDIA Nemotron 3 Super through Nebius Token Factory is the implemented inference path. Its OpenAI-compatible chat endpoint allowed the existing Python application to serialize matched requests without an additional SDK. Explicit model identity, JSON response format, finish reason and prompt/completion accounting made captured outputs assessable. Source-bound local SE6 results can be supplied to the assisted model while an isolated direct lane receives only shared public inputs.

The recorded October 28 integration used two actual requests: 477 prompt plus 67 completion tokens in the assisted lane, and 359 plus 67 in the direct lane. Both stopped normally and reported zero reasoning tokens. The published-tariff estimate was $0.0003714 combined; actual billing remains unknown. Assisted context contained a full correct conditional answer, so this observation demonstrates connection and serialization rather than superior independent reasoning. No new provider calls are authorized.

Earlier development encountered capped or malformed final outputs and incomplete comparisons. Clear per-model documentation for reasoning controls, guaranteed final-content budgeting, returned termination reasons and token accounting is important for bounded demos. Clearer billed-usage reconciliation and stable model/version provenance would improve reproducibility. A local response archive is not an independent provider signature or a model-weight attestation.
