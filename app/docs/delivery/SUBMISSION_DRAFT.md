# Devpost submission draft — review copy

**Project name:** SE6 Competition Edition — Inspectable Decisions and Verified Continuation

**Proposed track:** Best Apps and Agents. This is a bounded decision-and-evidence application, not an unrestricted coding agent. Final track selection belongs to the entrant.

## Inspiration and practical problem

A confident answer is difficult to trust when its dependencies change. A small team correcting a timesheet needs dependent calculations to update while unchanged facts survive. A developer changing a manifest or working directory needs the tool to repair the active configuration rather than a familiar but irrelevant file. SE6 Competition Edition makes those choices and their consequences inspectable.

## What it does

The existing web interface accepts supported tasks, runs the declared local mechanism once and displays the decision, observed evidence, exact effect, independent verification, retained state and resources. Its bounded dependency scenario connects raw manifest/configuration/CLI observations and actual operating context to a source-bound Native dependency operator. The permitted action changes one integer setting in a disposable project. A fresh CLI process verifies the real consequence; the existing Native renewal and Entity SQLite paths retain cross-referenced evidence for cold continuation through a changed dependency and working root.

The earlier supported service-business workflow separately derives job allocations and uses explicitly labelled deterministic HOST finance. A correction changes revenue and budget conclusions while preserving unaffected premises. Both workflows separate supplied assumptions from independently observed effects.

## NVIDIA and Nebius role

The implemented model path uses NVIDIA Nemotron 3 Super through Nebius Token Factory. A guarded pair coordinator serializes the same public question and answer contract for an assisted and direct request. Verified Native/HOST results are given only to the assisted lane; the model produces the final structured response. The application preserves the actual responses, usage, termination status and answer evaluation alongside local evidence. Source/question/cost-bound single-use approval gates the server-side credential path; page load and ordinary Native tasks make no provider call.

The recorded October 28 pair used `nvidia/nemotron-3-super-120b-a12b`, two requests and no retries. It is integration evidence: the assisted input contained the complete correct conditional answer. It does not prove better independent reasoning. Historical and new live data are visibly separate; a recorded response is never presented as a fresh call. All prior approvals are spent and current new-call allowance is zero.

## How we built it

The existing web application displays results and offers a safe export. ## Results and limitations

The preserved awareness sequence achieved 3/3 in retained SE6, 3/3 in narrow memory ablation and 3/3 in a competent conventional resolver. Nine permitted configuration changes had independent consequence evidence. Cold continuations covered changed dependency and actual root. SE6's retained relation influenced selection, but no goal-completion advantage was established. The conventional resolver used less measured worker CPU and wall time. Complete child-process CPU and local monetary costs remain unknown.

The admitted domain is a finite authored affine dependency relation with bounded integer configuration actions. This is useful bounded operational awareness, not subjective consciousness, general learning, autonomous primitive discovery or full mathematical realization of the owner equation. Current application acceptance is reported only from its actual saved run. Earlier tests are not a substitute for that execution.

## Challenges and lessons

Dependency correctness, provenance and cold continuity matter as much as a passing answer. Source pins need to cover the executing closure, not only a displayed formula. A stored decision must link to the exact action, independent consequence and renewed state. Negative and interrupted outcomes must remain inspectable without unsafe retries. Fair controls can tie; preserving that tie is part of the result.
