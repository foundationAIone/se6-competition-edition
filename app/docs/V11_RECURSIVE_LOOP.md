Artifacts use an exact JSON projection of native results; native tuples/checkpoints are not rewritten. Each effect is at most 8,192 bytes. Four nonrefunded attempts/effects are allowed per isolated task; a typical two-cycle run and correction exhaust them. Native workers retain their strict 20-second deadline, proof workers 12 seconds and fresh file readers 5 seconds. There are two shared computation permits. The whole recursive job consists of several bounded children and may exceed 20 seconds. Per-session limits are four public rounds, eight admitted attempts, twenty committed native receipts and ten minutes. Reset preserves action/attempt allowances and retires the old cookie. Failed attempts also consume their bounded worker time; committed-receipt counts are not all failed computation. The private session store has a 128-record lifetime cap; it is intentionally bounded and needs a reviewed retention policy for longer public operation.

## Evidence, correction and restoration

The primary answer/raw output binds the primary checkpoint. The final session checkpoint binds the automatic renewal. Per-cycle immutable native companions preserve their exact before/result context; a legacy one-round verifier must not combine a primary output with a final renewed checkpoint. Current field journals label this composite scope explicitly.

Changing native premises invalidates dependent deductions through the original native engine and preserves unaffected facts. Changing mapped-node identity supersedes dependent artifact context; this is a separate mechanism. Restoration verifies effects, ledger/seals, ancestry, companions, source/wrapper identities, native certificates and typed state. It uses the same compute permit as execution. A saved interrupted job, unresolved claim, orphan effect, changed source or inconsistent checkpoint fails closed and is not automatically retried. No atomic transaction or rollback across all files and memory is claimed. A native-only identity without a matching verified realization companion cannot regain native authority through a cold session restore.

Controller wall time, parent CPU, native CPU, proof CPU/counts, artifact bytes/actions and provider calls are reported. Reader-child CPU and local hardware monetary cost remain explicitly unknown; overlapping wall windows must not be added. No absent provider is scored. A changed field path or different artifact is not evidence of improved correctness, cognition, model weights, consciousness or full mathematical realization.
