# Public benchmark evidence projection

This is a derived, sanitized evidence package for foundationAIone/se6-competition-edition. It contains model request messages, selected model settings, final response content, returned token counts, locally observed elapsed times, tariff estimates and original hash anchors. It contains no approval text, authorization record, API credential, personal data, absolute local path, agent conversation, native checkpoint or private answer key. This is a draft for owner-approved release; preparing it does not publish it.

Run `python public_scorer.py .` from the package directory. The checker uses only Python's standard library and independently reconstructs exact row arithmetic and the supplied business calculations. It imports no SE6/vendor kernel, application service, private rubric or provider library and executes no network or inference. Optional tests: `python -m pytest -q test_public_evidence.py`.

The earlier schema failure remains visible and unmodified. Recommendations are unscored. Correction classification is reported separately, and unlike task scores are not aggregated into an overall winner. Successor usage-derived tariff estimate is $0.0037671: assisted $0.0025557, baseline $0.0012114. Prior campaign estimate is $0.0008922. Invoices remain unknown. Model requests were matched in settings but the assisted lane received additional disclosed verified calculations, so this measures tooling assistance rather than intrinsic model intelligence or an equal-compute comparison. One mixed pair is not statistical/general superiority evidence.

Public replay's zero inference count refers to replay, not historical execution: the package records two prior and six successor completed captures. Original transport byte counts and token/time observations are labeled separately from sanitized message byte sizes. The original prompt and its schema instructions are shared within each pair. Followup assistant content can be compared with each lane's own previous final response; the standalone tests verify that invariant and identical shared instructions. This proves consistency within this derived package, not cryptographic authenticity of remote model serving.

The checker also recomputes usage-derived tariffs and verifies reported original byte/output counts against declared numerical campaign limits. Successor captures report 28902 input bytes and 1349 completion tokens, within 49152 bytes/6144 total output tokens and 1024 per response. The prior limits were 16384 bytes/768 total output tokens and 384 per response. These public numerical limits are not approval records or new permission to execute either campaign. Actual native reservation enforcement and human authorization cannot be re-established from this projection alone.

Sanitization removes response IDs, exact timestamps, native receipt/source fingerprints, identity/provenance internals and absolute paths. Full approval, native state, original provider metadata and private keys remain private. Context JSON formatting is normalized, and the private records' exact wire bytes cannot be reconstructed from this package. Raw request/provider hashes are anchors to independently reviewed private originals, not hashes of the altered public messages. The derived-manifest hashes only public files; changing a public file invalidates that manifest.

Loss-of-provenance limit: the public reader can reproduce deterministic scoring and inspect declared lane independence, but cannot independently attest native authenticity, owner authorization, original exact wire hashes, event chronology or pre-capture answer-key isolation from these redacted files alone. The private campaign review verified all six captures and source/native/wire/reservation consistency before opening its rubric; only that review assertion is carried here. No private key is required for this public checker because expected arithmetic follows directly from the publicly supplied equations, hours, rates and budget. Answer disclosure occurs in a post-completion derived package and must never be fed back into a repeated campaign as if it were held out.

`PUBLIC_SCORECARD.json` is convenience output. Validated replay from `BENCHMARK_EVIDENCE.json` is authoritative for this public projection. Original score files and private capture manifests remain unchanged.
